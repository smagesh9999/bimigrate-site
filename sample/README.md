# Sample Desktop Pack

The website showcases a Studio batch produced from the public `sample_workbook.twb` fixture. The fixture was submitted as `Sales Performance Sample.twb`.

- `BI_Migrate_Studio_Sample.zip` contains the editable Power BI project, executive audit, and batch summary CSV.
- `BI_Migrate_Studio_Sample_Audit.pdf` is the executive audit included in that ZIP.
- `studio-audit-preview.png` shows the first page of that audit.

## Original Desktop Pack

Downloads:
- `BI_Migrate_Sample_Assessment.pdf` — assessment PDF preview
- `BI_Migrate_Sample_Desktop_Pack.zip` — full pack (PDF, gap matrix, semantic model, DAX, checklist)
